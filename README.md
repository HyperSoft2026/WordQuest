# WordQuest – رحلة الكلمات 🎮

لعبة ألغاز كلمات عربية بتصميم Mobile-first واتجاه RTL. هذه النسخة الأولى عبارة عن لعبة ويب قابلة للتشغيل مباشرة دون خادم أو قاعدة بيانات.

## التشغيل
- افتح `index.html` في متصفح حديث، أو انشر المستودع باستخدام GitHub Pages.
- لا تحتاج إلى تثبيت حزم أو إعداد مفاتيح سرية.

## الميزات الحالية
- واجهة عربية RTL متجاوبة مع الهواتف.
- شاشة رئيسية، خريطة مراحل، شاشة لعب، إنجازات وملف اللاعب.
- 12 لغزاً عربياً متدرج الصعوبة في نمط المراحل.
- نمط كلمات متقاطعة بتسع شبكات عربية تضم 55 كلمة: شبكتان 4×4، وشبكتان 5×5، وشبكة 6×5 بسبع كلمات وستة تقاطعات، وشبكة 7×6 بثماني كلمات وسبعة تقاطعات، وشبكتان متقدمتان 8×12 و8×10، تضم كل منهما عشر كلمات مترابطة وتسعة تقاطعات فعلية. وتضيف شبكة «عالم المعرفة» بقياس 11×13 عشر كلمات جديدة وتسعة تقاطعات متطابقة.
- تتضمن شبكة «عالم من حولنا» كلمات جديدة مثل حاسوب وحديقة ومدينة ونبات وورق، موزعة على خمسة أسئلة أفقية وخمسة عمودية.
- تتضمن شبكة «عالم المعرفة» كلمات قلم وكتاب وحديقة ومدرسة وشجرة ونهر ومكتبة وحاسوب وقمر ومدينة، موزعة على ستة أسئلة أفقية وأربعة عمودية.
- التحقق التلقائي من كل كلمة تكتمل نتيجة إدخال حرف في كلمة متقاطعة أخرى، مع منح مكافأة كل كلمة مرة واحدة فقط، واستعادة الكلمات الصحيحة المكتملة من التقدم المحفوظ.
- اختيار الشبكة والسؤال الأفقي أو العمودي، أو لمس خلية لاختيار الكلمة وموضع بدء الكتابة مباشرة؛ يظهر مؤشر الخانة التالية، وتُتجاوز خانات التقاطع المملوءة تلقائياً. تُعرض الخلايا بعرض لمس لا يقل عن 40px، وتُمرّر الشبكات العريضة أفقياً داخل حاوية مستقلة على الهاتف بدلاً من تصغير الخلايا. يمكن لمس حرف مُدخل لاستبداله مباشرة، مع حماية الحروف المشتركة التابعة للكلمات المكتملة.
- دعم التنقل بلوحة المفاتيح داخل الشبكة: الأسهم تتحرك بين خلايا الكلمة بحسب اتجاهها، ومفتاح المسافة يبدّل بين الأفقي والعمودي عند خلية تقاطع.
- تظهر شاشة تهنئة متحركة عند إكمال جميع كلمات الشبكة، وتُحفظ حالة عرضها مرة واحدة لكل شبكة حتى لا تتكرر عند إعادة فتح اللعبة؛ لا تضيف شاشة التهنئة مكافآت إضافية خارج مكافآت الكلمات المكتملة.
- يتيح زر شاشة التهنئة الانتقال مباشرة إلى الشبكة التالية غير المكتملة، ويتجاوز الشبكات المكتملة ويلتف إلى الشبكات السابقة عند الحاجة؛ تبقى جميع الشبكات متاحة للاختيار اليدوي.
- شريط تقدم مباشر لكل شبكة يعرض عدد الكلمات المكتملة والنسبة المئوية، ويتحدث تلقائياً بعد كل إجابة أو تلميح، مع إتاحة قيمة التقدم لقارئات الشاشة.
- تعرض أزرار اختيار الشبكات عدد الكلمات المكتملة من إجمالي الكلمات مع شريط تقدم مصغر ووصف وصول، لتسهيل متابعة الشبكات قبل فتحها.
- تلميح مدفوع بالعملات يكشف الحرف الصحيح التالي في الكلمة المحددة، مع احتساب إكمال الكلمة إذا أكملها التلميح.
- مؤثرات صوتية قصيرة مولّدة محلياً عند إدخال الحروف، والإجابات الصحيحة والخاطئة، والتلميحات والمكافأة اليومية؛ مع مفتاح تشغيل/كتم محفوظ على الجهاز.
- دعم إدخال الأحرف من لوحة اللعبة أو لوحة المفاتيح الفعلية، مع دعم Backspace للمسح.
- إدخال الأحرف من لوحة عربية، والتحقق من الإجابة، وإظهار أرقام بدايات الكلمات داخل الشبكة.
- حفظ الحروف والتقدم لكل شبكة على الجهاز، مع ترحيل حالة الشبكة الأولى القديمة ومنع تكرار مكافآت الكلمات المكتملة. تتضمن الشبكة ذات السبع كلمات ثلاثة أسئلة أفقية وأربعة عمودية، بينما تضم الشبكة المتقدمة خمس كلمات أفقية وخمساً عمودية.
- لوحة أحرف تفاعلية والتحقق من الإجابة.
- عملات ومكافآت عند إكمال المراحل.
- تلميحات: كشف حرف، إعادة المحاولة بأحرف جديدة، وكشف الحل.
- مكافأة يومية لمرة واحدة في اليوم.
- فتح المراحل تدريجياً وحفظ التقدم محلياً باستخدام `localStorage`.

## ملاحظات مهمة
- التقدم محفوظ على الجهاز والمتصفح الحالي فقط؛ لا يوجد حساب مستخدم أو مزامنة سحابية في هذه النسخة.
- المؤثرات الصوتية مولّدة محلياً عبر Web Audio API ولا تحتاج ملفات صوت خارجية؛ يمكن كتمها من الإعدادات. تعتمد على دعم المتصفح لـ Web Audio API وتبدأ بعد تفاعل اللاعب.
- قاعدة بيانات كلمات كبيرة ولوحة إدارة المحتوى ما زالت ضمن التطوير.
- لا توجد مدفوعات أو إعلانات مفعّلة.

## التقنية
HTML, CSS, Vanilla JavaScript. لا توجد dependencies خارجية إلزامية.
