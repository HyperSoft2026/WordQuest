# WordQuest – رحلة الكلمات 🎮

لعبة ألغاز كلمات عربية بتصميم Mobile-first واتجاه RTL. هذه النسخة الأولى عبارة عن لعبة ويب قابلة للتشغيل مباشرة دون خادم أو قاعدة بيانات.

## التشغيل
- افتح `index.html` في متصفح حديث، أو انشر المستودع باستخدام GitHub Pages.
- لا تحتاج إلى تثبيت حزم أو إعداد مفاتيح سرية.

## الميزات الحالية
- واجهة عربية RTL متجاوبة مع الهواتف.
- شاشة رئيسية، خريطة مراحل، شاشة لعب، إنجازات وملف اللاعب.
- 12 لغزاً عربياً متدرج الصعوبة في نمط المراحل.
- نمط كلمات متقاطعة بست شبكات عربية تضم 25 كلمة: شبكتان 4×4، وشبكتان 5×5، وشبكة 6×5 بسبع كلمات وستة تقاطعات، وشبكة 7×6 بثماني كلمات وسبعة تقاطعات فعلية.
- اختيار الشبكة والسؤال الأفقي أو العمودي، أو لمس خلية لاختيار الكلمة وموضع بدء الكتابة مباشرة؛ يظهر مؤشر الخانة التالية، وتُتجاوز خانات التقاطع المملوءة تلقائياً.
- تلميح مدفوع بالعملات يكشف الحرف الصحيح التالي في الكلمة المحددة، مع احتساب إكمال الكلمة إذا أكملها التلميح.
- مؤثرات صوتية قصيرة مولّدة محلياً عند إدخال الحروف، والإجابات الصحيحة والخاطئة، والتلميحات والمكافأة اليومية؛ مع مفتاح تشغيل/كتم محفوظ على الجهاز.
- دعم إدخال الأحرف من لوحة اللعبة أو لوحة المفاتيح الفعلية، مع دعم Backspace للمسح.
- إدخال الأحرف من لوحة عربية، والتحقق من الإجابة، وإظهار أرقام بدايات الكلمات داخل الشبكة.
- حفظ الحروف والتقدم لكل شبكة على الجهاز، مع ترحيل حالة الشبكة الأولى القديمة ومنع تكرار مكافآت الكلمات المكتملة. تتضمن الشبكة الأكبر ثلاثة أسئلة أفقية وأربعة عمودية.
- لوحة أحرف تفاعلية والتحقق من الإجابة.
- عملات ومكافآت عند إكمال المراحل.
- تلميحات: كشف حرف، إعادة المحاولة بأحرف جديدة، وكشف الحل.
- مكافأة يومية لمرة واحدة في اليوم.
- فتح المراحل تدريجياً وحفظ التقدم محلياً باستخدام `localStorage`.

## ملاحظات مهمة
- التقدم محفوظ على الجهاز والمتصفح الحالي فقط؛ لا يوجد حساب مستخدم أو مزامنة سحابية في هذه النسخة.
- المؤثرات الصوتية مولّدة محلياً عبر Web Audio API ولا تحتاج ملفات صوت خارجية؛ يمكن كتمها من الإعدادات. تعتمد على دعم المتصفح لـ Web Audio API وتبدأ بعد تفاعل اللاعب.
- قاعدة بيانات كلمات كبيرة ولوحة إدارة المحتوى ما زالت ضمن التطوير.
- لا توجد مدفوعات أو إعلانات مفعّلة.

## التقنية
HTML, CSS, Vanilla JavaScript. لا توجد dependencies خارجية إلزامية.
