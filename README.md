# WordQuest – رحلة الكلمات 🎮

لعبة ألغاز كلمات عربية بتصميم Mobile-first واتجاه RTL. هذه النسخة الأولى عبارة عن لعبة ويب قابلة للتشغيل مباشرة دون خادم أو قاعدة بيانات.

## التشغيل
- افتح `index.html` في متصفح حديث، أو انشر المستودع باستخدام GitHub Pages.
- لا تحتاج إلى تثبيت حزم أو إعداد مفاتيح سرية.

## الميزات الحالية
- واجهة عربية RTL متجاوبة مع الهواتف.
- شاشة رئيسية، خريطة مراحل، شاشة لعب، إنجازات وملف اللاعب.
- 12 لغزاً عربياً متدرج الصعوبة.
- لوحة أحرف تفاعلية والتحقق من الإجابة.
- عملات ومكافآت عند إكمال المراحل.
- تلميحات: كشف حرف، إعادة المحاولة بأحرف جديدة، وكشف الحل.
- مكافأة يومية لمرة واحدة في اليوم.
- فتح المراحل تدريجياً وحفظ التقدم محلياً باستخدام `localStorage`.

## ملاحظات مهمة
- التقدم محفوظ على الجهاز والمتصفح الحالي فقط؛ لا يوجد حساب مستخدم أو مزامنة سحابية في هذه النسخة.
- الأصوات، قاعدة بيانات كلمات كبيرة، ولوحة إدارة المحتوى ما زالت ضمن التطوير.
- لا توجد مدفوعات أو إعلانات مفعّلة.

## التقنية
HTML, CSS, Vanilla JavaScript. لا توجد dependencies خارجية إلزامية.
